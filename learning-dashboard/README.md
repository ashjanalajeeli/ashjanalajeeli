# ملفات لوحة التعلّم

هذا المجلد جزء من مستودع أشجان، ويحتوي على الواجهة التفاعلية ومصدر بيانات التقدّم:

- `index.html` — صفحة الملف التعليمي.
- `styles.css` — تنسيق الواجهة ودعم الشاشات الصغيرة.
- `app.js` — إنشاء مخططي الأعمدة والدائرة وملخص الإنجاز.
- `progress.json` — أعداد الدروس المنجزة حسب المسار.

الرسم المختصر الظاهر مباشرة في ملف GitHub الشخصي موجود في `../assets/progress-dashboard.svg`، لذلك يمكن مشاهدة المهارات والتقدّم من الملف الشخصي دون الانتقال إلى صفحة أخرى.

## التشغيل المحلي

من هذا المجلد شغّلي خادمًا محليًا حتى تتمكن الصفحة من قراءة JSON:

```bash
python3 -m http.server 8000
```

ثم افتحي `http://localhost:8000`.
